# akshatpaul.com — Astro Site

## How the site works

This is a static Astro site migrated from WordPress. Content lives in `public/` as HTML files. The site uses clean Astro components for layout — no WordPress/Elementor bloat on blog pages.

- `src/pages/index.astro` — serves the homepage (`public/index.html`) unchanged
- `src/pages/[...slug].astro` — catch-all route: renders blog posts in `PostLayout`, serves other HTML files raw
- `src/pages/blog/index.astro` — clean Astro blog listing page (NOT from public/)
- `src/pages/sitemap.xml.ts` — auto-generates sitemap by scanning `public/`
- `src/layouts/PostLayout.astro` — clean layout for all blog posts (nav, header, prev/next, footer)
- `src/layouts/BaseLayout.astro` — base HTML shell (fonts, CSS vars)
- `src/components/SiteNav.astro` — shared nav component
- `src/components/SiteFooter.astro` — shared footer component

## Adding a new blog post

You only need to provide: **content HTML, title, date, slug, tag, excerpt.**

### Step 1 — Create the content file

Create `public/{slug}/index.html` with just the article content (no nav/header/footer needed):

```html
<!DOCTYPE html>
<html>
<head>
  <meta charset="UTF-8">
  <title>Your Post Title — AkshatPaul.com</title>
  <meta property="article:published_time" content="2026-01-15">
  <meta property="og:description" content="Short excerpt for the blog listing card.">
</head>
<body>
  <!-- Article content goes here — just the body HTML -->
  <p>Your content...</p>
  <h2 id="section-one">Section One</h2>
  <p>More content...</p>
</body>
</html>
```

The `PostLayout` wraps this automatically with the site nav, header, prev/next navigation, and footer.

**No need for:** WordPress HTML shell, Elementor classes, gtag snippet, wp-content CSS links.

### Step 2 — Register the post in `[...slug].astro`

Add the slug to `POST_ORDER` at the top of `src/pages/[...slug].astro` (newest first):

```ts
const POST_ORDER = [
  { slug: 'your-new-post-slug', title: 'Your Post Title' },
  // ... existing posts
];
```

### Step 3 — Add to blog listing

Add the post to the `posts` array in `src/pages/blog/index.astro`:

```ts
{
  slug: 'your-new-post-slug',
  title: 'Your Post Title',
  date: '2026-01-15',
  excerpt: 'Short description shown on the blog listing card.',
  tag: 'React Native',  // or AWS, Ruby, iOS, etc.
},
```

Add it at the top of the array (newest first).

### Step 4 — Build

```bash
npm run build
```

This regenerates the sitemap and compiles all pages.

`robots.txt` points to `https://akshatpaul.com/sitemap.xml`.
